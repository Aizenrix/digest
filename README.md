# Дайджест новостей

Лента новостей разработки и технологий для модуля 4. Утром n8n читает Хабр, GitHub Changelog и Cloudflare Blog. Ollama готовит короткие пересказы и теги. Дайджест читается из опубликованного Apps Script. Вечером n8n отправляет подборку в Telegram.

## Запуск

Нужен Node.js 24 LTS. Скопируйте `.env.example` в `.env` и укажите публичный адрес Apps Script в `VITE_DIGEST_URL`. В GitHub Actions используется переменная репозитория с тем же именем.

```sh
npm ci
npm run dev
npm run lint -- --deny-warnings
npm test
npm run build
```

Поиск, тег и «Только непрочитанные» действуют вместе. Параметры фильтров в адресной строке можно скопировать. Отметка прочтения хранится в браузере. Даты и группировка отображаются по Москве.

## Автоматизация

1. Создайте отдельную Google Таблицу. В связанном Apps Script вставьте [Code.gs](automation/apps-script/Code.gs). Запустите `setupDigest` в редакторе. Функция создаст лист `news`, ключ записи и пятиминутный триггер.
2. Разверните Apps Script как веб-приложение от имени владельца с публичным чтением. Скопируйте адрес `/exec`. В `automation/.env` задайте `DIGEST_URL`, ключ из свойств скрипта `DIGEST_KEY` и номер чата. Используйте шаблон [automation/.env.example](automation/.env.example).
3. Установите в Ollama `qwen3:4b-instruct`. Поднимите n8n командой `docker compose up -d` из папки `automation`. В редакторе по адресу `http://127.0.0.1:5684` импортируйте [утренний](automation/n8n/morning.json) и [вечерний](automation/n8n/evening.json) процессы. В узле Telegram выберите учётные данные бота.
4. Опубликуйте процессы. Утренний запуск назначен на 08:00, вечерний на 19:00 МСК. Docker и Ollama должны работать в это время.

Apps Script проверяет ключ и ставит новые записи в очередь. Связанный триггер переносит их в лист с дедупликацией по ID и обновляет публичный снимок последних 45 новостей. Такая схема сохраняет доступ к текущей таблице при запуске веб-приложения. [Ограничения связанных скриптов](https://developers.google.com/apps-script/guides/bound#special_methods).

Для вечерней подборки настроены `ИИ`, `программирование`, `безопасность` и `интернет`. Параметр `DIGEST_TAGS` принимает список через запятую. Строка без тегов включает все новости последних суток.
