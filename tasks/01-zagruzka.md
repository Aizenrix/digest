# 1. Загрузка и карточки новостей

Загрузить `news` с адреса из `VITE_DIGEST_URL`. Разобрать строку тегов и даты. Показать заголовок со ссылкой в новой вкладке, источник, дату с московским временем, пересказ и отдельные метки тегов.

Пока запрос выполняется, показывать `role="status"`. При ошибке показывать `role="alert"` с HTTP-кодом, если сервер ответил. Добавить повтор загрузки.

## Готово, когда

- Новые карточки выше старых. Тест проверяет порядок и внешнюю ссылку.
- Подменённый ответ HTTP 500 даёт сообщение с кодом. Сетевая ошибка позволяет повторить запрос.
- TypeScript, строгий линтер и тесты проходят.
