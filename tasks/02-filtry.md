# 2. Поиск, тег и непрочитанные

Добавить регистронезависимый поиск по названию и пересказу, выбор одного тега и фильтр непрочитанных. Сочетать условия, вычислять видимые новости при отрисовке, показывать счётчик и сообщение для пустого результата. Сохранять настройки фильтра в URL. Сгруппировать карточки по московским датам.

## Готово, когда

- Тесты проверяют поиск, тег, совместное действие фильтров, пустой результат и открытие адреса с параметрами.
- Поля имеют подписи и доступны с клавиатуры.
- Изменение фильтра не загружает новости повторно.
