# 4. Утренний сбор и вечернее сообщение

Собрать два процесса n8n. Утром брать новости за сутки из Хабра, GitHub Changelog и Cloudflare Blog, пересказывать через Ollama, валидировать теги и записывать пакет. Вечером отбирать последние новости по разрешённым тегам и отправлять в Telegram сообщение с заголовками и ссылками.

Подготовить связанный Apps Script с доступом к текущей таблице, приватным ключом записи и публичным JSON. При повторе сохранять одну запись на ссылку.

## Готово, когда

- Расписание в n8n соответствует 08:00 и 19:00 МСК.
- Неправильный ключ отклоняется, повторный пакет не дублируется, а чтение возвращает строку тегов.
- Ручные прогоны показывают реальные новости в таблице и доставку сообщения.
