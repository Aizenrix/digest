# Правила проекта для агента

- Основная лента использует React 19, TypeScript и Vite. Версия Angular 21 разделяет с React валидацию, форматирование и CSS.
- Используй Node.js 24 LTS. Перед коммитом выполни `npx tsc -b`, `npm run lint -- --deny-warnings`, `CI=true npm test` и `npm run build`.
- Условия приёмки лежат в `tasks/`. Пиши конкретные результаты проверок в `ai-log.md`. Различай результаты агента и приёмку владельцем.
- Адрес GET берётся из `VITE_DIGEST_URL`. Ответ имеет вид `{"news":[{"id":"https://example.org/post","date":"2026-11-20T08:00:00Z","source":"Лента","title":"Заголовок","summary":"Пересказ","tags":"ИИ, наука","link":"https://example.org/post"}]}`.
- При чтении `tags` — строка через запятую. При записи n8n передаёт массив тегов. Сортируй по дате, считай фильтры при отрисовке, сохраняй только ID прочитанных под ключом `digest.read.v1`.
- Для статусов используй `role="status"` и `role="alert"`. Проверяй подписи, клавиатуру и видимый фокус.
- В тестах интерфейса подменяй `fetch`. Ключ записи находится в Google Script Properties и локальной конфигурации Docker, токен Telegram — в учётных данных n8n.
